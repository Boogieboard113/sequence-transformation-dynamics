# Sanitized research snapshot

Public author credit: **Boogieboard113**.

This package presents the finite-cyclic mathematical core, source proofs and errata, exact reference code, fixtures, tests, and a worked quickstart. It is a research snapshot, not a declaration that all STD problems are solved. See [results and limits](RESULTS.md).

The development process used AI-assisted mathematical and computational work with internal nonauthor review. This export reports that review status from private records; the underlying discussion and source-control records are not included for public verification. External peer review, formal verification, and a comprehensive novelty assessment have not been completed.

The export omits Git history, account/profile links, commit identifiers, internal task boards and chat coordination, workflow logs, and original nested archive bundles. ZIP timestamps and permissions are normalized, with no owner IDs, archive comments, or extended metadata. Historical source identifiers in retained text and generated evidence are marked as omitted. `SHA256SUMS` records new checksums for the actual exported files.

Mathematical algorithms and proof arguments are preserved. The malformed-certificate runner has a snapshot-local checksum adapter in place of its private-checkout gate. Tests tied only to omitted historical checkout and archive infrastructure are excluded; all included tests and the adapter are exercised on this package. See [validation results](VALIDATION.json).

This removes identified direct links in the package, not every possible means of attribution. Distinctive research text can be matched if another copy becomes public. The account used to publish, its profile and past activity, and future commits can also reveal connections. Use the intended pseudonymous publishing account and verify its public profile before upload. This package has not been published and does not contain a Git repository.

A public-use license has not been selected. Choose the intended license before representing the project as open source. Pending analyzer work and unaccepted theorem extensions are not part of the reviewed-core snapshot.
