# Fixed-length horizons can oscillate with the source length

**Date:** 2026-10-11  
**Status:** candidate internal theorem; Researcher C author; independent nonauthor mathematical review passed on the claim, source-format repair pending exact-head confirmation.  
**Issue:** #87.

## 1. Model

Take binary source and output alphabets and the radius-zero identity transformation.

Let
- U = 0011, with primitive period 4;
- V = 000111, with primitive period 6;
- m = 7.

Let W7 be the union of all periodic length-7 windows of U-infinity and V-infinity.

For each positive integer N, let X_N be the set of rooted binary cyclic words of exactly length N whose periodic length-7 windows all lie in W7.

When X_N is nonempty, define H_N(2) to be the least positive source histogram order h such that equality of raw cyclic C_h implies equality of output C_2 on X_N.

No convention is imposed for empty fixed-length domains.

## 2. Theorem

For every N with X_N nonempty:

- H_N(2) = 2 if 12 divides N;
- H_N(2) = 1 if 12 does not divide N.

Moreover,

X_N is nonempty if and only if 4 divides N or 6 divides N.

Thus the exact fixed-length horizon depends periodically on the prescribed source length.

## 3. Exact source-domain classification

The periodic length-6 windows of V-infinity are its six rotations. Each contains a run of three equal symbols.

No length-6 window of U-infinity contains three equal consecutive symbols, because every constant run in U-infinity has length two.

Therefore the length-6 vertex sets generated by the two periodic orbits are disjoint.

Within either orbit, advancing one source site maps every length-6 vertex to one unique successor and one unique predecessor. Hence the allowed length-7 higher-block graph is exactly the disjoint union of:

- one directed simple cycle of length 4, generated by U;
- one directed simple cycle of length 6, generated by V.

This graph argument also covers N < 7. A length-N admissible cyclic source induces an N-step closed walk in the same higher-block graph by periodic wrapping. A closed walk on a directed simple cycle of length c returns to its starting phase exactly when c divides N.

Therefore every admissible source is a rotation of a positive power of U or a rotation of a positive power of V, and X_N is nonempty exactly when 4 divides N or 6 divides N.

## 4. Exact fixed-length horizon

For one primitive period,

C_1(U) = (2,2)
and
C_1(V) = (3,3).

Hence every length-N source from either orbit family, whenever it exists, has

C_1 = (N/2, N/2).

The periodic pair counts are:

C_2(U)(00,01,10,11) = (1,1,1,1)

per four sites, while

C_2(V)(00,01,10,11) = (2,1,1,2)

per six sites.

### Case 1: 12 does not divide N

Assume X_N is nonempty and 12 does not divide N. Exactly one of 4 divides N or 6 divides N holds.

Therefore all sources belong to one orbit family and are rotations of the same fixed power of U or V. Raw cyclic C_2 is rotation-invariant, so all sources have the same output C_2.

Thus source order h = 1 is sufficient and H_N(2) = 1.

### Case 2: 12 divides N

Both orbit families occur. Choose

X = U^(N/4)
and
Y = V^(N/6).

They have equal C_1 = (N/2,N/2), but

C_2(X)(01) = N/4
and
C_2(Y)(01) = N/6,

which are different. Therefore h = 1 fails.

Because the transformation is the identity, source C_2 equals output C_2 exactly. Hence h = 2 always suffices.

Therefore H_N(2) = 2.

This proves the theorem.

## 5. Concrete boundary examples

At N = 12,

X = (0011)^3 = 001100110011
and
Y = (000111)^2 = 000111000111

have common source C_1 = (6,6), while C_2(01) equals 3 for X and 2 for Y.

At N = 4, only the four rotations of 0011 occur, so H_4(2) = 1.

This shows explicitly why an unrestricted-length cross-support obstruction need not survive at every prescribed source length.

## 6. Computational support

The companion standard-library checker:

- literally filters all 2^N rooted binary words for every N from 1 through 12 using periodic length-7 windows;
- compares each literal domain with the two-cycle classification;
- checks the exact horizon on every predicted fixed-length domain for N from 1 through 48;
- preserves the N = 12 witness.

The exhaustive rooted-word counts for N = 1,...,12 are:

0, 0, 0, 4, 0, 6, 0, 4, 0, 0, 0, 10.

These finite checks support the proof; they are not the basis of the universal claim.

## 7. Scope and limitations

This theorem concerns only the stated fixed-length binary cyclic finite-type domain, identity transformation, and output order 2.

It does not provide:

- a general fixed-length support-pair algorithm;
- a theorem for fixed inventories or upper-count constraints;
- an extension of unrestricted rational scaling to nonhomogeneous domains;
- a rooted inverse-counting theorem.

The accepted unrestricted-length PR #6 theorem remains logically separate and unchanged.
