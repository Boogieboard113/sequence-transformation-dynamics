# Proof notes and their status

The [result index](../docs/RESULTS.md) describes the mathematical core included in this snapshot and its scope. The directories `candidates` and `proved-internal` reflect historical development stages. Some candidate notes were subsequently accepted internally; an old header is not the current scope statement.

Proofs and errata are included for inspection. Private account identifiers, source-control history, and internal coordination records are omitted. Historical review claims are not a substitute for public independent review, and this export has no proof-assistant or external peer-review certification.
