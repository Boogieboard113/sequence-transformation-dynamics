# Related work and publication positioning

This is an introductory comparison, checked against primary author/publisher sources on 12 October 2026 UTC. It is **not an exhaustive literature review or evidence of originality**. The connections below are editorial comparisons; the cited works do not endorse or validate STD.

| Literature | Connection to STD | Distinction to preserve |
|---|---|---|
| Lind and Marcus, *An Introduction to Symbolic Dynamics and Coding*; [author's contents](https://faculty.washington.edu/lind/symbolic-toc/) and [book page](https://faculty.washington.edu/lind/symbolic-book/) | Higher-block presentations, finite-type restrictions, graphs, and sliding block codes are established symbolic-dynamics tools | A variable-length or erasing word-emission rule is not automatically the usual length-preserving sliding block code |
| Karhumäki, Saarela, and Zamboni (2013), [*On a generalization of Abelian equivalence and complexity of infinite words*](https://arxiv.org/abs/1301.5104) | k-abelian equivalence compares factor counts through order k; closely related to equality of source block statistics | Their stated definition concerns finite linear words. STD's raw periodic windows have cyclic boundary conventions; translating results requires proof |
| Karhumäki, Puzynina, Rao, and Whiteland (2016), [*On cardinalities of k-abelian equivalence classes*](https://arxiv.org/abs/1605.03319) | Connects equivalence classes and de Bruijn graph cycle decompositions | Counting equivalence classes differs from determining transformed statistics on an entire class |
| N. G. de Bruijn (1946), [*A combinatorial problem*](https://research.tue.nl/en/publications/a-combinatorial-problem/), volume 49(7), pp. 758–764 | Historical reference for the de Bruijn sequence setting underlying the familiar overlap-graph language | Use of de Bruijn graphs is not itself an originality claim |

The defensible present description is: **a research project assembling exact cyclic-statistic questions, scoped theorems, witnesses, and reproducible reference implementations**. The project title is not a claim to have founded a previously unknown field.

Before making theorem-specific novelty claims, a manuscript needs a fuller comparison of its exact domain, erasure assumptions, cyclic conventions, and conclusions with existing factor-count equivalence, transducer, graph-circulation, and cohomological results. It should identify which statements are standard tools, reformulations, new combinations, or potentially new results. This preparatory bibliography does not settle that comparison.
